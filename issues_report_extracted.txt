Issue 4: No Multi-Episode Training or Train/Test Split
Paper States (Section VI)
"The Q-learning agent was trained for 500 episodes using the standard VeReMi train/test split convention adopted in prior work, where 70% of the traces are used for training and 30% for testing."
Code Reality
The code performs a single sequential pass over all BSMs in a scenario. There is:
No concept of "episodes" or repeated training passes
No splitting of data into training and testing subsets
No separate training phase followed by evaluation
No mechanism to iterate through data multiple times
The accuracy is computed cumulatively over the single pass.
Concern
500 episodes of training allows Q-values to converge toward stable policies. A single pass provides minimal learning opportunity. The accuracy curves in the paper almost certainly cannot be reproduced from a single-pass approach — yet that is all the code implements.
Required Action
Implement the 500-episode training loop with 70/30 split as described.
Show that Q-values converge over episodes.
Demonstrate that the reported accuracy curves (Figures 5-8) emerge from this training procedure.
